## 🚗 Fuel Calculator
Fuel Calculator is an Android application that helps users estimate how much money they will spend on fuel to reach their destination.

## 🔧 How It Works
The app asks for three key pieces of information:

💰 Gasoline price per liter

📍 Distance to be traveled (in kilometers)

🚘 Car fuel consumption (km per liter)

Based on this input, it calculates the total cost of the trip and displays the result clearly in a summary table.

## 🖥️ Features
Displays all entered values and the final result in a simple, clean table format.

Allows users to go back to the home screen and make a new calculation easily.

Designed with a minimalistic and dynamic layout using a custom color palette I selected to ensure a pleasant and user-friendly experience.
